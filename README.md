# Verdant (مدیریت مالی شخصی) — اندروید

اپلیکیشن مدیریت مالی شخصی با React Native و Expo، فقط برای اندروید. داده‌ها روی گوشی ذخیره می‌شوند (AsyncStorage) و بدون اینترنت کار می‌کنند.

## اجرا
```bash
npm install
npx expo install --fix      # هماهنگ‌سازی نسخه‌ها با Expo SDK 51
npx expo start --android    # با گوشی متصل (USB Debugging) یا شبیه‌ساز
```
برای ساخت فایل نصب APK یا AAB:
```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease     # خروجی: app/build/outputs/apk/release
```
در اولین اجرا، چیدمان راست‌چین پس از ری‌استارت کامل اپ اعمال می‌شود.

## بخش‌ها
- **داشبورد:** موجودی کل، درآمد و هزینه‌ی این ماه، پس‌انداز کل، نمودار دایره‌ای هزینه‌ها و حالت تاریک
- **تراکنش‌ها:** ثبت، ویرایش و حذف درآمد، هزینه و پس‌انداز؛ جستجو؛ فیلتر بر اساس نوع و دسته؛ انتخاب تاریخ با تقویم شمسی
- **اهداف:** تعریف هدف، افزودن پس‌انداز با بررسی موجودی، نوار پیشرفت و حذف هدف
- **گزارش‌ها:** نمودار هفتگی و ماهانه، خلاصه‌ی ماه، و هزینه به تفکیک دسته

## قوانین و اصلاحات انجام‌شده
- اعداد منفی و کاراکترهای غیرعددی هنگام ورود مبلغ حذف می‌شوند؛ مبلغ‌ها باید بزرگ‌تر از صفر باشند و سقف مبلغ مشخص است.
- تاریخ آینده برای تراکنش مجاز نیست.
- پیشرفت هدف از روی تراکنش‌های پس‌انداز همان هدف محاسبه می‌شود، پس حذف یا ویرایش یک پس‌انداز، مجموع‌ها را درست نگه می‌دارد.
- حذف یک هدف، پس‌اندازهای آن را هم حذف می‌کند و مبلغ به موجودی برمی‌گردد.
- فرم‌ها با `KeyboardAvoidingView` و حالت `resize` در اندروید، پشت کیبورد پنهان نمی‌شوند.
- اجزای لمسی حداقل ۴۸ پیکسل هستند و کارت‌ها گوشه‌ی ۱۶ پیکسلی دارند.
- نمودار دایره‌ای و اندازه‌ی کارت‌ها با عرض صفحه تنظیم می‌شوند.
- لیست تراکنش‌ها با `FlatList` و کامپوننت memo شده برای روان ماندن روی گوشی‌های قدیمی.
- هر صفحه هنگام باز شدن با انیمیشن محو وارد می‌شود.
- داده‌های خراب یا ناقص هنگام بارگذاری حذف می‌شوند تا برنامه کرش نکند.

## محدودیت‌ها
- روی دستگاه واقعی و شبیه‌ساز اجرا نشده است؛ پیش از انتشار تست دستی لازم است.
- آیکون ساده‌ی سه‌بعدی (کیف پول طلایی) است و برای انتشار در Google Play می‌توان با طراحی حرفه‌ای جایگزین کرد.
- هنوز تست خودکار ندارد.
